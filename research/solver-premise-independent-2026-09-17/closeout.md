## What emerged independently

The repository did not naturally reduce to a catalog of heuristics. The strongest independent structure is a research-function topology:

`encode -> derive -> generate -> reject -> prefer -> retain -> remember -> allocate -> select -> transfer -> recognize -> measure -> infer`

The structure needs at least four cross-cutting axes:

1. **epistemic authority** — referee truth, proved feasibility, safe dominance/equivalence, heuristic prediction, empirical experience, diagnostic correlation, scheduler prior/default;
2. **evidence scope** — implementation, population, budget, architecture, measurement, and intervention role;
3. **architecture/configuration dependence** — the proposition being tested can change when representation, repair operators, stage order, budget semantics, or continuation capabilities change;
4. **temporal validity** — historical conclusions may survive, narrow, or reopen after architecture changes.

Several open parent questions emerged from missing links rather than from free-form brainstorming, especially:

- how long search-produced information remains useful and how far it should transfer;
- whether failure can become a legal, useful posterior over the next action;
- whether hard residuals are primarily missing alternatives or losing/starving valid ones;
- whether extinction of known-solution support predicts the intervention that will rescue a level;
- what level of state relatedness is appropriate for proof, compression, experience, and transfer;
- how to separate intrinsic mechanism value from conditional portfolio value;
- what object should generalize: static level shape, dynamic failure state, obligation configuration, or trajectory.
