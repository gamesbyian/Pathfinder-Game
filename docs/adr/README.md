# Architecture decision records

Architecture decisions remain here whether accepted or superseded so the reason for each boundary
is recoverable. The canonical status and title list is maintained in the
[`docs` index](../README.md#current-references); each ADR's own status controls if the two disagree.

Read the ADR matching the boundary being changed before editing architecture. Superseded ADRs are
history, not current implementation guidance; their successor is named in both the ADR and the main
index.
