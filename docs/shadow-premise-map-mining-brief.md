# Blind shadow-mining brief

> **Mode:** independent interrogation of a fixed map.
> **Frozen input:** repository state at commit `e9601ffb8fa304d5ea91d054a9de6cb1bf8ff28e`.
> **Goal:** discover higher-order insights from the frozen solver premise map using an interrogation method invented independently in this investigation.

## Input boundary

Treat the map and supporting files at the frozen commit as the complete research object.

Do not inspect repository commits, branches, pull requests, reports, or map versions created after the frozen commit, except commits you create on this branch for your own work.

Do not use outside summaries of later mining, later synthesis, later map admissions, or downstream research results.

## Method rule

Before recording substantive discoveries:

1. inspect the frozen map as a research object;
2. design your own interrogation approach without consulting any later mining method;
3. write down and freeze that approach;
4. then execute it.

If the method changes after findings begin to appear, preserve the original method and log the change as post-hoc.

Do not optimize the method to reproduce an expected answer.

## Output discipline

Keep distinct:

- method design;
- method-specific observations;
- synthesized insights;
- alternative interpretations;
- negative findings;
- uncertainty;
- observations that may reflect representation limitations rather than research-space structure.

Every substantive finding should be traceable to frozen-input material.

## Stop rule

Close the shadow-mining investigation before viewing any later mining or synthesis lineage.

At closeout record:

- exact branch head;
- frozen input identity;
- interrogation method and any post-hoc changes;
- evidence/provenance;
- known blind spots;
- confirmation that post-freeze comparison material was not inspected.

Do not edit the frozen map, create a successor map, alter the solver queue, or perform reconciliation on this branch.
