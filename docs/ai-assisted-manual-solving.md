# AI-assisted manual solving: compatibility pointer

> **Status:** worked 2026 methodology note consolidated into the current research operating model.

The durable method is [`solver-research-operating-model.md#accepted-path-differential-diagnosis`](solver-research-operating-model.md#accepted-path-differential-diagnosis): a human/AI-constructed path is useful only after the canonical referee accepts it, provenance is recorded honestly, and the unchanged solver's trace is compared against that accepted path.

Do not mine an AI's post-hoc narrative as causal evidence. The path and measured search divergence are the evidence.
