## New current-state method, not a depth29 special case

[The source-only 12-parent measurement](stress/pg-i-mechanic-bucket-debt-census-20261019-001.json) found **7/12** independent parents with substantial original `mechanicBucketRetention` displacement of their scorer's own global top512, including **33,967** global top512 displaced candidate occurrences across **543** bucket-selection phases. This qualifies exactly one model-independent, source-current-scored-frontier treatment, not a guarantee that score is more predictive of feasible completion than rare mechanic diversity.

At every phase where `beamSearchFromGate` would use bucket retention, compute its **original unchanged bucket-selected frontier** first. If explicitly opted into the research-only Boolean `researchProtectTop75MechanicBucket`, then reselect **384 / 512** beam positions using the already ranked global top positions, followed by at most **128** remaining positions from the original bucket-selected frontier in its original order; if still short, fill by global score. This preserves every high-ranked global top75% candidate, while retaining a constrained minority-diversity tail. It does not inspect past solver outcomes or identify historical solution paths, parents, depths or tiles. At any width the same fraction uses `floor(0.75*width)`, but this experiment tests only **width512**. This fraction is *chosen once*, motivated by the previous rank329 failure (within global top384), not tuned after seeing these source outcomes.

The original fast default uses exactly the unchanged mechanic-bucket selection. The opt-in reuses the original result, so a phase with no meaningful displacement should act identically apart from the pure array copies. A pure generic helper and isolated tests establish no duplicates, protected top score prefix, bounded width, no mutation and fail-closed malformed floor.
