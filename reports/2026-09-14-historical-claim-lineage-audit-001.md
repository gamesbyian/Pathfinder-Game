## Question

The first resource audits established a causal evidence lineage:

`population -> variant family -> transferred/discovered path -> hint provenance -> Solution Profile / path diagnostic`.

The later inference-first audits extended it downstream:

`... -> experiment population -> execution/participation -> interpretation -> capability memory -> question state -> workstream action`.

This audit asks whether older solver conclusions gained confidence by counting descendants of one upstream observation as independent evidence, by turning a selected witness into a whole-level property, or by treating nominal exposure as meaningful capability testing.

## Finding 1 — family -> replay -> hint -> Profile is one lineage unless independently broken

The cross-resource audit established that replay is upstream of most of the stored accepted-path sample: 206,558 / 266,997 paths are replay-touched and 200,773 are replay-only in recorded origin terms. Every current published/C1/C2 parent is replay-touched.

Therefore these are not automatically independent confirmations:

- a generated family exposes a parent-valid path;
- the path is imported as hint/provenance evidence;
- a Solution Profile summarizes that path sample;
- a path-derived diagnostic describes a representative from the same sample.

Agreement can be coherent and useful while still being one causal ancestry family.

**Reuse rule:** when an old mechanism claim cites several of these descendants, collapse them to one ancestry source unless the analysis explicitly filters lineage or adds an independent current intervention.

This changes confidence multiplicity, not the literal observations.

## Finding 2 — the July `fragile` / `robust` split overreached on cause

`2026-07-16-phase-c-family-variant-solve-analysis.md` observed a real perturbation-response contrast. R02248 solved in many generated relatives; R00440 solved in none of its tested relatives. That descriptive contrast survives.

The report then interpreted wide failure across transformations and attempt profiles as a signature of **genuine combinatorial hardness**, implying the robust group was not a good scoring target and likely required bounds/pruning/new technique.

That causal step is not earned by the retained evidence.

Why:

1. **Parent, not variant row, is the independent unit.** Forty-five siblings do not constitute 45 independent demonstrations of a cause.
2. **Generated families are conditioned interventions.** Accepted siblings survive operator eligibility, witness preservation and validation. Failure across that retained intervention set proves resistance to those perturbations, not intrinsic hardness of the parent.
3. **Technique spread is not mechanism independence.** Several attempt profiles can share scoring, state representation, ordering, pruning, predecessor history, or the same missing completion abstraction.
4. **No current reference model proves the parent requires exhaustive/combinatorial search.** A future capability can make an apparently robust level cheap.
5. **Later Phase D already moved toward the correct boundary.** Its robust comparison explicitly says n=2 is inconclusive and cannot explain what makes a level robust.

The safe interpretation is:

- `fragile`: this selected parent showed high solver-response sensitivity under the tested family interventions;
- `robust`: this selected parent resisted the tested family interventions under the tested solver/budget;
- neither label identifies the latent cause by itself.

This does **not** invalidate the family resource. Perturbation response remains a useful nomination phenotype. It only removes the inference `robust -> intrinsic combinatorial hardness`.

### Current blast radius

No solver rerun is justified.

## Finding 3 — the fragile-family ablation line remains useful, but its evidence role is discovery

The July/August orientation line is stronger than the robust causal claim because it contains actual interventions:

- transformed siblings preserve puzzle validity;
- hard/easy solve-status cliffs were observed under the solver;
- individual scoring flags were ablated;
- several selected parents showed rescues under different ablations.

That supports the existence of representation-sensitive finite-search failures and rejects a single universal score-term explanation on the inspected cases.

It does **not** estimate prevalence. The parents/variants were selected because they exhibited the phenomenon, and the five cases are descendants of the same family-screening program. Calling them several parent-level cases is safer than treating every family/hint/Profile/path descendant as a new independent vote.

The current synthesis already contains the important scope limit: the 38-family study was selected and the five ablation cases cannot estimate corpus-wide frequency. Its current recommendation, diagnose cliffs before intervention and require canonical cold-solve evidence, remains sound.

## Finding 8 — exact matched-row experiments remain stronger than ancestry-rich observational syntheses

The recent audits sharpen a useful hierarchy for old evidence:

1. **exact matched execution with verified treatment identity, participation and work** — strongest causal reuse;
2. **current isolated/intervention evidence with explicit context** — capability evidence, but placement may remain open;
3. **family perturbation / ablation evidence** — controlled discovery at the parent level, selected if nominated by outcome;
4. **replay/hint/Profile/path summaries** — observational descendants whose ancestry must be collapsed;
5. **report-only legacy conclusions** — nominative when primary reconstruction or modern identity is unavailable.

This explains why the portal-forced-neighbour promotion, portal global-placement negative, current portal freshness and must-turn rescue evidence survive, while old family/Profile syntheses require narrower language.

## What should not be rerun

Do not launch broad historical replication merely to obtain modern metadata or independence counts.

Specifically, this audit does not earn:

- a new 38-family orientation campaign;
- a new R00440/R02579 robustness campaign;
- a bulk replay-free Profile rebuild solely for history;
- the frozen alternate-oracle cohort without a live representative-path claim;
- broad Class-3 recomputation solely to complete a table.

A live decision should buy the smallest counterfactual that can change that decision.

## Durable rule for future archaeology

Before reusing an old multi-source mechanism argument, draw its ancestry as:

`population selection -> intervention/generation -> path discovery/replay -> provenance store -> summary/diagnostic -> experiment -> capability -> question state`.

Then ask:

1. which observations have genuinely different parents/interventions rather than different representations;
2. whether a selected witness became a whole-level claim;
3. whether nominal presence became nonzero participation and comparable dose;
4. whether solver-outcome/residual selection narrowed the population;
5. whether the historical conclusion suppresses or nominates live work today.

Only item 5 justifies expensive corrective experimentation.

## Closeout

The newer resource audits fit the first four as downstream inference and control-plane layers, and the combined lineage is now coherent enough that the next useful move is solve-directed research rather than another archaeology program.

The key new correction is modest but important: **perturbation robustness is an observed response phenotype, not proof of intrinsic hardness**. More broadly, confidence should count causal ancestry, not the number of files or derived representations that repeat the same observation.
