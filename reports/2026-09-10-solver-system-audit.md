| 9 | Pruning / rejection | done | Audited the shared hard-prune gauntlet, lower bounds/deadlock helpers, connectivity/topology pruning, parity/portal restoration, and the known-solution-prefix observation path. | 10 | Caching / dedup / state reuse | done | Exact memoization paths are now guarded for cardinality/axis identity (`mustPassLowerBound`, `mustCrossLowerBound`) and safely bypass packed caches beyond supported cardinalities. Beam coarse-state merge is intentionally **not** an exact state-equivalence cache: it omits full visited/edge history and can discard a globally winning lineage; portal merge therefore remains default-off pending fixed-work evidence, and the coarse-state-disabled retry exists precisely because this capability loss is real. Treat beam coalescing as an algorithmic approximation/capability axis, never as proof that two futures are equivalent. |
| 11 | Profiles / configuration / defaults | done | Swept AttemptConfig identity/dispatch invariants and default polarity. The dispatcher now rejects unknown scoring profiles instead of silently falling back to `default`; repair configs cannot masquerade under a scoring identity they do not implement; beam-only flags cannot be attached to DFS; family subflags cannot appear without their family; invalid beam widths are rejected; and custom ordering-bias behavior cannot hide behind a canonical ID. Dedicated contract tests cover these impossible/misleading configurations. Audit 12's fresh-work-pool split was the remaining registry/read-polarity defect found in this pass and is fixed behaviorally at the shared retry executor. |
| 12 | Retry / rescue / escalation | done | Audited the five whole-ladder retry treatments as a family. A retry now has one cross-layer eligibility invariant: its forced treatment must change the caller's effective configuration. Execution enforces that in `runWholeLadderRetryTier`; allocation uses the same helper before computing reserves/stacked ceilings. Thus a second funded pass cannot be behavior-identical to the failed pass it follows, cannot receive false rescue credit, cannot strand a subtractive reserve, and cannot leak additive headroom into later stages while itself being skipped. Fresh-work-pool default polarity is also normalized at the shared executor. Family-level tests cover default treatments plus all five behavior-identical cases. |
| 13 | Termination / exhaustion | done | No termination-correctness defect found. Production `failed` remains deliberately weaker than proof of search-space exhaustion. The suspicious beam phase bound around portals is valid: a portal pair cannot be repeatedly consumed because its terminals become visited and cannot be re-entered, so `requiredLength + portalPairCount` is a valid upper bound for that phase. Continue to keep budget exhaustion, policy abandonment, and explicit bounded-technique exhaustion distinct in evidence/reporting. |
| 14 | Resumability / cross-technique continuation | reopened/fixed | Found a serious retained-continuation lifetime bug: `BeamContinuation` referenced per-`PrepLevel` pooled mutable beam buffers, so retaining beam A, dispatching beam B, and later resuming A could mutate/corrupt A's supposedly paused state. The dispatcher now detaches retained continuations by copying mutable path/visited/edge/constraint/undo storage while sharing the immutable frontier; ordinary non-capturing beam runs pay no copy. Regression coverage now exercises the previously-missing multi-beam lifetime pattern: pause A, run B on the same prep, assert A's retained arrays are unchanged, then resume A to the uninterrupted reference result (`7b3356de`). A second apparent contract issue was reclassified after tracing the call path: resuming a retained frontier under a changed scoring/order/width/retention policy is intentional and supports policy-switch complementarity research, so only `startKey`/level/prep ownership must match; the interface prose that implies identical policy is stale documentation, not a runtime defect. True cross-technique continuation (for example beam → DFS/repair) is not implemented: current resumability is beam-frontier reuse, including deliberate beam-policy switching. Treat that as a capability gap to test, not a broken promise. |
