| 1 | Solver contract and end-to-end correctness | done | Worker SOLVE transport had drifted from direct `SolveResult`: it dropped `staticPortfolioWinningConfigKey` and the new `resumableResidualPass` telemetry. Aggregate `failed` (production) vs `exhausted` (static portfolio) remains intentional: production policy termination is not a proof of search-space exhaustion; the explicitly bounded static portfolio can report natural technique exhaustion with budget remaining. |
| 2 | State representation / search-space model | done | Reconciled mutable solver state against `docs/mechanic-state-contracts.md` and the schema cardinality guards. The core state carries the dynamic legality/win state expected for edge use, visits/intersections, must-pass/cross, portals, flippers, and landmarks. Found a boundary hole instead: both public raw-level ingress paths could normalize representation-unsafe raw data without the cardinality/bounds/occupancy checks that protect bitmasks and typed arrays. Added solver-safety raw validation to `createSolver().prepareLevelForSolver()` and worker `SOLVE`, while deliberately preserving rectangular synthetic solver fixtures: square-grid enforcement is a publishing/content invariant, not a solver representation invariant. Internal `normalizeRawLevel` remains permissive for synthetic research/test fixtures. Regression tests cover both public seams. |
| 3 | State identity / equivalence / canonicalization | done | Repair's experience-cache `stateSignature` omitted `path.length` and the immediately previous cell even though future feasibility/scoring depends on remaining length and incoming/chirality context. Two non-equivalent repair states could therefore inherit the same prior-failure experience and suppress useful randomized exploration. Added counted path length plus previous-cell identity to the signature and regression tests for both distinctions. This cache is advisory rather than a soundness prune, so the defect was capability loss rather than false UNSAT. |
| 4 | Successor generation / search actions | done | Audited DFS/LDS, beam, repair, admissible-order, prep-time static adjacency, and the independent PLAY referee. Production search families share the same `getNeighbors`/`applyMove` transition substrate and first-step must-cross forcing; portal, gate-reentry, edge-axis, must-cross-turn, filter, flipper, length/intersection, and landmark rules are independently rechecked by the referee. Apparent solver-vs-PLAY differences for geese/false-goal traversal are intentional dead-end elision/analysis behavior, not a reachable-solution omission. This audit reopened Audit 2 and caught the over-broad square-grid validation before closeout; that was narrowed to representation-safety validation. |
| 5 | Technique implementation and capability | done | The shared AttemptConfig dispatcher correctly routes DFS/LDS, beam, repair, and admissible-order families, and the parallel worker is structurally guarded against re-forking dispatch logic. Found one technique-identity/capability mismatch: a programmatic repair config could set both `repairMustTurnBiased` and `repairTurnBiased`, execute a hybrid with both mechanisms active, but canonicalize as only `must-turn-biased`. That let behaviorally distinct search contaminate provenance/census evidence under an existing identity. Canonical identity formatting and dispatch now reject the unrepresentable hybrid, with regression coverage. |

| 7 | Scheduler and stage participation | done | Audited canonical stage registry/order, `StageBudgetPlan` eligibility, `SolverStagePlan`, executors, and attempt `stageId` tagging. No live selected-but-never-participates path was found. The parity guard had not been extended when the two newest promoted stages (`guidance-goal-distance-retry`, `late-repair-multiseed-retry`) were added, leaving a future drift seam despite correct current wiring. Added a regression test asserting their scheduler eligibility exactly mirrors the budget plan. |
| 8 | Budget and work accounting | done | Audit 12 exposed two retry-budget drifts and both are now closed. First, promoted `STRATEGY_GOAL_ATTRACTION_DISABLED_RETRY_FRESH_WORK_POOL` still had an opt-in-only call-site read; the canonical whole-ladder executor now treats null/unset as fresh and only explicit `false` as shared. Second, the executor's new behavior-distinctness guard could skip a retry whose forced override was already effective while `stage-budget.ts` still reserved capacity for it. The stable budget facade now applies the executor's exact `retryTierOverridesChangeBehavior` semantics before the unchanged allocation cascade: behavior-identical retry strategy reads are presented as disabled without mutating/copying normalized config proxies. This covers all five shared whole-ladder retries. The goal-attraction retry no longer withholds main-search nodes for an inert pass, and inert additive retries no longer inflate ceilings inherited by later stages. Focused regression coverage checks both the subtractive and stacked-additive cases. The stale pre-executor fresh-work calculation/comment in `orchestration.ts` remains redundant cleanup debt; runtime behavior no longer depends on it. |
| 9 | Pruning / rejection | done | Audited the shared hard-prune gauntlet, lower bounds/deadlock helpers, connectivity/topology pruning, parity/portal restoration, and the known-solution-prefix observation path. No new unsound hard prune was found. Soundness-sensitive restorations have explicit conservative abstention rules plus stored-solution/oracle replay evidence; portal parity has dedicated invariants; the beam research observer raises a correctness alarm whenever a known-supported prefix is actually removed by hard pruning. Repair deliberately skips the must-cross neighbor-budget candidate removal where changing the survivor set would perturb seeded stochastic behavior; that weakens pruning but cannot create false rejection. Beam merge/width culling is not classified as admissible pruning and is handled under Audit 10. |
| 10 | Caching / dedup / state reuse | done | Exact memoization paths are now guarded for cardinality/axis identity (`mustPassLowerBound`, `mustCrossLowerBound`) and safely bypass packed caches beyond supported cardinalities. Audit 3 fixed the repair-local advisory experience signature. Enumeration-worker prep caching uses a fresh per-run caller key, preventing normal cross-level reuse. Beam coarse-state merge is intentionally **not** an exact state-equivalence cache: it omits full visited/edge history and can discard a globally winning lineage; portal merge therefore remains default-off pending fixed-work evidence, and the coarse-state-disabled retry exists precisely because this capability loss is real. Treat beam coalescing as an algorithmic approximation/capability axis, never as proof that two futures are equivalent. |
| 11 | Profiles / configuration / defaults | done | Swept AttemptConfig identity/dispatch invariants and default polarity. The dispatcher now rejects unknown scoring profiles instead of silently falling back to `default`; repair configs cannot masquerade under a scoring identity they do not implement; beam-only flags cannot be attached to DFS; family subflags cannot appear without their family; invalid beam widths are rejected; and custom ordering-bias behavior cannot hide behind a canonical ID. Dedicated contract tests cover these impossible/misleading configurations. Audit 12's fresh-work-pool split was the remaining registry/read-polarity defect found in this pass and is fixed behaviorally at the shared retry executor. |
| 12 | Retry / rescue / escalation | done | Audited the five whole-ladder retry treatments as a family. A retry now has one cross-layer eligibility invariant: its forced treatment must change the caller's effective configuration. Execution enforces that in `runWholeLadderRetryTier`; allocation uses the same helper before computing reserves/stacked ceilings. Thus a second funded pass cannot be behavior-identical to the failed pass it follows, cannot receive false rescue credit, cannot strand a subtractive reserve, and cannot leak additive headroom into later stages while itself being skipped. Fresh-work-pool default polarity is also normalized at the shared executor. Family-level tests cover default treatments plus all five behavior-identical cases. |
| 13 | Termination / exhaustion | done | No termination-correctness defect found. Production `failed` remains deliberately weaker than proof of search-space exhaustion. The suspicious beam phase bound around portals is valid: a portal pair cannot be repeatedly consumed because its terminals become visited and cannot be re-entered, so `requiredLength + portalPairCount` is a valid upper bound for that phase. Continue to keep budget exhaustion, policy abandonment, and explicit bounded-technique exhaustion distinct in evidence/reporting. |
| 14 | Resumability / cross-technique continuation | reopened/fixed | Found a serious retained-continuation lifetime bug: `BeamContinuation` referenced per-`PrepLevel` pooled mutable beam buffers, so retaining beam A, dispatching beam B, and later resuming A could mutate/corrupt A's supposedly paused state. The dispatcher now detaches retained continuations by copying mutable path/visited/edge/constraint/undo storage while sharing the immutable frontier; ordinary non-capturing beam runs pay no copy. Regression coverage now exercises the previously-missing multi-beam lifetime pattern: pause A, run B on the same prep, assert A's retained arrays are unchanged, then resume A to the uninterrupted reference result (`7b3356de`). A second apparent contract issue was reclassified after tracing the call path: resuming a retained frontier under a changed scoring/order/width/retention policy is intentional and supports policy-switch complementarity research, so only `startKey`/level/prep ownership must match; the interface prose that implies identical policy is stale documentation, not a runtime defect. True cross-technique continuation (for example beam → DFS/repair) is not implemented: current resumability is beam-frontier reuse, including deliberate beam-policy switching. Treat that as a capability gap to test, not a broken promise. |
