# Measurement-completion hardening closeout

> **Status:** concluded-positive
> **Last evidence:** 2026-09-17 — seven candidate measurement families were reconciled against canonical v2, Phase-2 discriminators/primitives, the independent peer map, shadow mining, and cross-reconciliation.
> **Decision:** preserve a typed measurement-opportunity overlay under governing premise P204; admit no new canonical premise IDs and do not reopen broad mining.
> **Remaining gate:** broader representation-hardening / map-v3 work should decide how this overlay is indexed/validated in the successor representation; this pass itself does not earn v3.

## Scope

This pass tested a narrow concern:

> Does the current premise map under-represent useful *observables* that could distinguish mapped rival explanations?

It did not search the repository for a new general solver ontology and did not treat telemetry ideas as premise candidates by default.

## Why P204 is sufficient as the semantic parent

P204 already states that observations support causal conclusions only insofar as they discriminate materially different rivals.

The missing representational unit is therefore not another premise asserting that measurement matters.

It is a typed record of:

- the unresolved ambiguity;
- the candidate observable;
- what rival explanations it separates;
- relevant mapped premises;
- whether the opportunity is saturated, under-explicit, or blocked.

This is now captured by:

- `docs/solver-premise-map-measurement-completion-hardening.md`;
- `docs/solver-premise-map-measurement-opportunities.json`.

## Anti-expansion rule

The overlay must not become a telemetry backlog.

An entry is legitimate only when:

- a live mapped ambiguity exists;
- the observable can discriminate it;
- current telemetry does not already do so;
- collection legality/censoring/work/authority can be stated;
- a result would change an actual research decision.

This is deliberately stricter than "would be interesting to measure."

## Successor-map disposition

This pass alone does not earn v3.

It does strengthen the case that a successor representation should support typed non-premise research objects such as:

- measurement opportunities;
- experimental primitives;
- representation qualifications;
- reopen conditions.

Whether those live in one overlay schema or several remains a representation-hardening decision.

Frozen v1 and v2 remain untouched.

## Mining disposition

No new broad mining round is earned.

A future bounded audit may ask:

> For each materially unresolved map region, is there a missing discriminating observable?

That is a hardening/completeness check, not recursive mining of every possible telemetry idea.

## Solver queue disposition

None.

No measurement opportunity becomes a solver work item without an independently earned premise-to-falsifier path and expected decision value.
