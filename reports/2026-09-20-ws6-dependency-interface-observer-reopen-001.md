## Reconciliation with Lane E

Lane E stays closed in its tested form.

Its exact CP-SAT bisection asked whether the true point of no return lies materially later than ordinary DEAD/LIVE divergence, providing a smaller causal rollback target.

On the fresh R03147 regime:

- four tested DEAD trajectories had seven moves of nominal rollback room;
- two independent divergence points were represented;
- every exact point of no return was exactly the first DEAD/LIVE divergence;
- the critical move family was `plain`.

Combined with B2, Lane E had enough evidence to close that tested premise. This observer does **not** rerun or weaken that negative.

The surviving WS6 question is different:

> if the divergence move is already the causal boundary, what future-relevant commitment does the DEAD branch make that the LIVE branch avoids?

A useful answer might still be a current-state relational/topological/resource fact even when its first appearance is at ordinary divergence.

## Why this is now cheap

The exact labels, matched pairs, divergence depths and point-of-no-return bisections already exist.

No new:

- solver search;
- CP-SAT query;
- frontier sampling;
- repair rollout;
- family generation;

is needed for the first observer.

The recent research-system work also removes the old need to force a cross-level fixed descriptor. A generic current-input derivation may emit a board-specific dependency fact; recurrence is required only before claiming a reusable fixed descriptor or general production policy.

## Frozen development population

Use only retained Lane E rows where:

1. the DEAD row has an exact matched LIVE sibling;
2. the stored `pointOfNoReturn.infeasibleDepth` equals `naiveFirstDivergence`;
3. DEAD and LIVE share the prefix immediately before that depth;
4. both branch states replay legally through current canonical solver transitions.

This selects the R03147 early-divergence regime already used by Lane E.

The primary independent unit remains the **divergence point**, not downstream continuation. Several DEAD continuations sharing one divergence are corroborating descendants, not extra independent evidence. All are from one parent, so this first pass is a microscope only.

## Frozen projection

Replay the common prefix and each branch through current solver state semantics. Immediately after the divergent move, record the following.

### 1. Global exact accounting

- counted length used/remaining;
- intersections used/remaining;
- pending must-pass status from `mpVisitedMask`;
- pending must-cross mask;
- pending must-turn mask;
- pending surround mask;
- pending adjacent-turn mask;
- flipper-used mask;
- portal jumps and consumed portal-pair identity where derivable.

### 2. Local path-resource state

- whether the branch target was already visited;
- target-cell edge-usage state;
- number of unique visited cells;
- number of revisited cells;
- number of cells with horizontal, vertical or both axes already consumed;
- raw legal successor count from the post-move state.

Exact cell IDs may be retained for forensic replay but are **not** themselves a semantic success criterion.

### 3. Existing production hard-prune response

Run the current hard-prune gauntlet observationally on the already-applied branch state and record:

- pass/reject/solution;
- canonical reached/rejected prune IDs.

An exact-LIVE branch rejected by the current production gauntlet is a correctness alarm and blocks interpretation.

If the DEAD branch is already rejected by an existing hard fact while the LIVE branch passes, WS6 has rediscovered an existing consumer rather than a new dependency interface.

### 4. Branch geometry, as a negative control

Record raw branch direction/target identity separately.

A distinction consisting only of “the paths take different cells/directions” is not a dependency interface.

## Frozen interpretation

Classify each independent divergence point into the first applicable category:

1. **existing-hard-fact**: DEAD is rejected by a current sound production prune and LIVE is not;
2. **bounded-semantic-delta**: a non-positional state/resource projection differs DEAD vs LIVE while both remain otherwise comparable;
3. **geometry/history-only-at-this-resolution**: only branch cell/direction or raw visited/edge layout differs;
4. **blocked**: replay, identity, exact-label or correctness alarm.

### Advancement rule

This one-parent microscope cannot earn a repair operator.

It may nominate a broader observer only if both independent R03147 divergence points show a coherent **bounded-semantic-delta** in the same semantic family, or if one exposes an existing exact/current-input fact that clearly defines a new testable dependency relation.

Otherwise record the microscope negative/insufficient and leave dependency-conditioned repair dormant.
