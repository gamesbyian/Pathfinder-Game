## Strict native treatment contract

A *different scorer's earlier real attempt* must have computed `isConnected` at the exact same source gate, full packed path, per-path visit/axis footprint, all mechanic state scalars, and sorted full effective ablation config. Only then may the later scorer reuse that result. Width5000 `objectiveFirst` and `intersectionHarvest` are the only allowed consumers/producers; same-scorer repeats or a different width/gate always run the original flood.

The cache retains both the Boolean **and the full fresh reached bit rows**, not the Boolean alone. A hit calls `restoreConnectivityReachRowsForExperiment`, which validates grid dimensions/bit ranges and makes `_reached` read the reconstructed bit-parallel bitmap for the current branch. The following real flood automatically resets its own BFS/bitmap representation. `_rowPassable` and `_rowVisAny` belong to the original in-flood algorithm, while downstream reach tests use `_reached`; their freshness is why the prior [PG-L 008](2026-10-19-pg-l-reach-row-exact-reuse-preflight-001.md) measured complete masks.

The original `isConnected` still executes on all nonhits. `neutral` cache hits restore scratch but also atomically charge the full 12 units to both canonical work meters, respecting the same strict cap refusal before the operation. That makes any changed search decision, node count, attempt order or result an explicit **semantic falsification**. `saving` hits restore scratch but do *not* pay that 12-unit native charge, so actual total-budget 250k phase scheduling may change. Work saving is reported as native 12×confirmed hit events, never as a claim about CPU speed.

The opt-in object is **per-solve PrepLevel**, not global, with max 80k entries / 16M serialized key characters; a cap marks the experiment censored and disqualifies interpretation. Result-containing research observers are incompatible because skipping their original flood callbacks would change experimental side effects. No hints, stored solve outcomes or parent IDs ever reach production policy.
