Date: 2026-09-17

## Audit posture

Assume the phase is wrong in the most tempting ways: that an attractive cross-lane story survived because vocabulary was mistaken for mechanism; that D1's labelled separation was mistaken for runtime economics; that row counts were inflated into independent evidence; or that queue wording silently authorized implementation.

## Findings

### 1. Correlation -> causation

**Checked / contained.**

F3's 7/9 tied-discordant agreement remains a diagnostic correlation only. It receives no selector authority. Lane A's separator prevalence remains structural coverage, not proof that decomposition would improve search. D1's exact association with LIVE/DEAD on the retained cohort is not described as the cause of death or as proof that ranking on the signal improves solves.

### 2. Shared evidence counted as independent

**Real hazard found and corrected before this audit.**

D1's 18 DEAD + 2 LIVE states / 220 queries are all from one parent (`R03147`). The phase consistently treats that as one-parent evidence. F3 counts seven parent families rather than 31 puncture rows. Lane A counts levels rather than 4,862 measured interfaces.

### 3. Residual properties generalized to Pathfinder

**Contained.**

Lane A's 121/390 statistic is explicitly current Class-5 residual coverage, not a global Pathfinder frequency. D1 is a selected production-frontier cohort. F3 is a constructed topology-fork population. None is promoted to a whole-game claim.

### 4. Constructor/sampling effects mistaken for solver semantics

**Contained.**

D1's multi-pick cohort is recognized as constructor-selected and one-parent after matching. F3 construction-admissibility and tied/untied coverage are kept separate from runtime prevalence. A's residual formation is treated as lineage-conditioned.

### 5. Old negatives transported across architecture epochs

**No new transport.**

The phase relies on current solver seams and current evidence. Historical vocabulary is used only as lineage context; no old negative is treated as current proof without matching the tested mechanism/epoch.

### 6. Information-valued work treated as free

**Contained and outcome-changing.**

D1's exact information cost is not hand-waved away. The retained campaign used 220 CP-SAT queries, but elapsed time was not retained; therefore the economics report refuses to invent a cost distribution. This missing cost is one reason the line stops.

### 7. Missing consumer state confused with missing puzzle state

**Explicitly separated.**

Lane A has the relevant puzzle state but lacks a proven compact cross-interface representation. D1 has the state and consumer seam; its missing pieces are information computation/economics. F3 has path geometry but lacks a reliable cheap descriptor on decision-bearing tied cases.

### 8. Generated vs selected failure conflated

**Contained.**

D1's retained states existing in the labelled cohort does not prove that a D1 ranking would cross a beam cutoff. The economics falsifier explicitly records that sibling scores, frontier rank, cutoff and coarse-state retention context were not retained. Therefore 18 zero-feasible DEAD states are not counted as 18 current-policy disagreements.

### 9. Renamed historical work hidden by current documentation

**No material hidden duplicate found in this phase.**

The current consumer seams were checked against current beam/scoring/retention behavior and archaeology-aware authorities. No prior generic producer-consumer subsystem or equivalent D1 production mechanism was discovered that would make this work a renamed duplicate.

### 10. Scope distinction given an unnecessary new premise

**Contained.**

No new premise IDs were admitted. The consumer-contract distinctions are applications of P201-P206 and existing operating-model rules. The failed common-interface hypothesis is a relation/scope conclusion, not a new semantic premise.

### 11. Ontology/interface gap mislabeled as solver mechanism

### 12. Offline replay trusted despite feedback

D1's precise reopen trigger is observation/measurement, not a command to add instrumentation. A/F3 stay at their existing representation/opportunity gates. This is applied in the closeout authority update.

### 14. Completion claimed without validation/repository state

**Guardrail carried forward from Phase 3.**

This phase will not call itself complete until final diff, review threads/reviews and opportunistic CI are checked after the final authority/closeout commits. PR text must report pending checks as pending.

## Procedural lessons retained

1. **Validate authority budgets as semantic constraints.** Phase 3 showed that a legitimate handoff can still break CI if a canonical context file is near its ceiling. Do not expand the queue authority by appending history; replace obsolete active-gate prose with compact dispositions.
2. **Audit compaction for lost gates.** Passing a byte budget is not enough. Every compacted authority change must be checked for reopen conditions, population qualifiers and no-restart constraints.
3. **Count independent units before effect sizes.** Establish ancestry before interpreting rows, queries, punctures or interfaces.
4. **Require a real selection boundary.** A signal is not a consumer merely because some function could read it.
5. **Treat missing retained fields as a result.** If economics require score/cutoff/work ancestry and those fields were not retained, record the measurement gap; do not infer them from labels.
6. **Fail hypotheses cleanly.** The common-interface synthesis failed its own pass condition. No post-hoc weakening of the bar was used to preserve it.
7. **Do not recurse indefinitely.** The execution plan ends after Phase 3. This post-plan descendant may advance only through its own explicitly earned gates; its retained-evidence D1 gate now stops.

## Audit disposition

No defect found that changes the substantive phase conclusion after the D1 ancestry correction and explicit retained-evidence economics stop. The required final work is repository/authority closeout and validation, not another research mechanism.
