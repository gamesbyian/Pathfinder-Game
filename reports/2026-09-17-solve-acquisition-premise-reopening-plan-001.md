## Why a new premise ladder is needed

The current production boundary is strong enough that the remaining residual is no longer yielding obvious additive treatment gates. Class 4's portal-coarse capability was successfully harvested with a dead-last additive treatment, while the subsequent Class-5 hypothesis ladder mostly closed tested forms:

- H1 event feasibility: closed negative in its frozen vocabulary;
- H3 repair-commitment interface: closed negative on Card-E;
- H2 structural stasis: closed negative;
- naive behavioral quotient: exact-equivalence claim falsified, Card-E partial purity retained only as nomination evidence;
- DEAD-core: not closed, but population-limited after 3/4 exact-DEAD B2 states showed a size-1 causal core.

Open-path topology remains the strongest causal crack: matched same-board/same-endpoint prefixes can differ in exact LIVE/DEAD status solely with a path-history topology change. The legal production design space is therefore broader than another scalar feature or global retry.

## Direct corrections completed in this pass

### 1. Class-3 epistemic status repaired in the live authority

The September 12 cheap-harvest report described Class 3 as reached/comparable-work-failed. The September 14 historical claim-lineage audit explicitly withdrew that inference: dispatch/reach does not prove exact-action comparable dose.

The live workstream authority now says Class 3 is **dose-unverified rather than proven negative** and permits only a bounded evidence reconciliation unless a live decision justifies more compute.

This matters because a systematic dose/placement failure could create a genuinely changed allocation premise. Conversely, verified comparable exact-action dose with continued failure would close an ambiguity that has survived several queue generations.

### 2. Separator/decomposition census is now prespecified

Added `docs/solver-separator-decomposition-census-preflight.md`.

The preflight separates four mechanisms that must not be blurred together:

- static board separators;
- mechanic-aware separators;
- path-history-conditioned separators;
- portal-mediated interfaces.

It requires interface-width, region-balance, mechanic-state, length/intersection coupling and construction-cost measurements before any architecture is built. The key failure mode is **contract explosion**: a geometrically narrow cut is useless if its correct state contract recreates nearly the full global history.

A positive census earns only the smallest bounded descendant, preferably an interface-feasibility prune or local exact query before region DP/AND-OR machinery.

### 3. Fresh exact sibling asset is now prespecified

Added `docs/solver-fresh-dead-sibling-harvest-preflight.md`.

The immediate consumer is DEAD-core confirmation, but the population is intentionally reusable for separately prespecified topology, exact-query and behavioral microscopes. Selection is frozen before labels and preserves parent-level independence.

The campaign sizes from its own exact-DEAD opportunity rate rather than reusing the observed 3/4 small-core rate from the exhausted B2 set.

The missing DEAD-core test is explicit: derived conflicts must reject other DEAD siblings while sparing LIVE siblings before runtime nogood/conflict machinery is earned.

## Execution order now recorded in the live queue

### 1. Separator/decomposition census

This is the cheapest remaining architecture falsifier and can expose several capability descendants at once. Run it before implementing decomposition.

Possible positive descendants:

- sound interface-feasibility prune;
- topology-conditioned accessibility prune;
- bounded exact subproblem query;
- region-contract DP / AND-OR search;
- backward interface contracts;
- per-level compiled decomposition plan.

### 2. Fresh exact LIVE/DEAD sibling harvest

Acquire one well-provenanced residual-selected population instead of repeatedly mining bespoke exact-labelled microsamples.

Use it first for DEAD-core confirmation.

### 3. DEAD-core confirmation and per-instance topology microscope

These are complementary rather than competing:

- DEAD-core asks whether failure can yield a small sound conflict reusable within the invocation;
- topology asks whether a generic current-input procedure can derive completion-relevant board-specific facts even when no universal descriptor recurs.

A topology result does not need the identical relation to recur across levels if the generic derivation procedure itself generalizes.

### 4. Bounded Class-3 exact-action dose reconciliation

Do this only if the evidence is cheaply recoverable from current telemetry/artifacts. Do not launch broad recomputation merely to complete the table.

Decision outcomes:

- systematic under-dose / placement starvation -> changed allocation premise, potentially reopening a treatment gate;
- verified comparable exact-action dose with failure -> close the old ambiguity;
- insufficient telemetry -> document the evidence gap and leave Class 3 unresolved until a future live decision warrants instrumentation.

### 5. Card-E quotient interaction discovery

The current quotient is not production-safe state equivalence. Its Card-E purity beyond random and length-blocked nulls is nevertheless enough for a small hypothesis-generation pass.

Use only a tiny interpretable expression/interaction space, hold out whole parent families, and treat any fitted rule as a nomination. Distill survivors into named legal hypotheses and independently confirm them before they can reopen WS1.

### 6. Complete-path LNS cheapest falsifier

This is the best independent search-object challenge to the forward-prefix architecture, but implementation is premature.

First ask whether plausible relaxed complete paths are structurally close enough to accepted solutions that bounded local surgery has a credible basin. A null result cheaply closes the route; a positive result earns a prototype.
