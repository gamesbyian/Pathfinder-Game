## Result and clear stop decision

The [read-only replay run 39008955611](https://github.com/gamesbyian/Pathfinder-Game/actions/runs/39008955611) reused the exact frozen `capture.json`/`cases.json` from PG-H-002. Every one of the eight parent/gate attempts reproduced its original **canonical workSpent exactly**. Total original work across the eight gates was **2,705,853**, so this is the same 500k-work-capped objectiveFirst width-500 search, not a new search geometry or budget.

| Measured opportunity | Result |
|---|---:|
| Exact-DEAD frozen child prefixes | 35 |
| Independent parents / sibling groups | 8 / 16 |
| Children with no later retained parent expansion | **28** |
| Children with later retained parent expansion | **7** (one event each, across 3 parents) |
| Parent expansion work attributed below these 35 child prefixes | **0** |
| Cases requiring no new already-terminal test from PG-H-003 | 33 |
| Work budget exercised across all eight original attempts | **2,705,853** |

The seven later-expanded children are `R00242:g458762:s0:d58:c0`, `R00242:g458762:s1:d58:c0`, `R02941:g524294:s1:d70:c1`, and four `R02561:g196615:s{0,1}:d53:c{0,1}` children. Their parent expansion records each carry **zero** metered work because they are dead at that expansion stage. For the other 28 child prefixes the beam never retains a parent expansion at all.

**Interpretation:** An oracle-confirmed dead child need not be a profitable prune target. On the exact intentionally deepest-selected sample, a new hard rejector would add cost at the candidate seam but remove little measured downstream work, with no demonstrated additional solve or retained beam-slot opportunity. This is a scoped economic **negative** for a new late-deadness consumer at this beam dose, not a proof that semantic deadness is unimportant elsewhere. It does **not** mean discarding the 2 genuine shallow forced-state witnesses from PG-H-001.

The observer counts `parentExpansions[].workSpent`, not all possible local decision/ranking overhead or downstream alternative-tier work. Zero here is **zero instrument-attributed expansion work**, not a theorem that removing these children costs or saves absolutely nothing under a new policy. In a finite-width beam, removing apparently dead children can still alter which alternative children occupy the frontier, so any new consumer would still need a soundness proof and a matched-work A/B if a future economically promising population is found.

### Follow-up with explicit gate

- Do **not** buy a second 20-second-per-child CP-SAT campaign restricted to extreme depth. It found exact DEAD fates but negligible retained work.
- Use the **same passive generated-parent observer** to stratify intermediate *remaining counted steps*, real portal usage, outstanding must-pass/cross obligations, and genuine subsequent expansion-work. Choose informative sample strata *before* asking exact references, and preserve independent parent grouping.
- The earlier R00242 early forced-sibling contrast remains positive (one LIVE, one DEAD in each of two states). A cheap solve-local discriminator can be tested without a production oracle but must generalize, remain sound for hard pruning, and show actual opportunity.

## Design

The original `semantic-forcedness-capture.mjs` emits complete typed child prefixes. Rerun **the same frozen** production-observer beam, this time counting each generated frontier parent's path when it begins with a frozen child prefix. Accumulate `parentExpansions[].workSpent` only when descendants of that child are actually expanded. The observer never changes neighbor order, score, prune, width or work cap.

A descendant may be generated but never retained, which must be reported as **zero subsequent parent expansions**. A nonzero count reveals a measurable opportunity; it does not prove a new prune would improve cold solves, because frontier-slot displacement, wall overhead and other attempts remain unmeasured. Prevent double-counting if any frozen child prefix is nested under another: report both per-child totals and unique parent-event union cost.

The resulting deepest-selected form is now closed after the exact 28/35 zero-retention result. Keep the original stop protocol as the preregistered decision rule; future work uses intermediate counted-length rather than this same near-terminal class.
