## Earned shared primitives

Only two new shared structural owners survived the promotion rule:

`research-unit-topology-lib.mjs` owns the recurring role names:

- observation;

- assignment;
- dependence cluster;
- analysis;
- generalization.

It does not own specialist unit values, estimands, sampling or causal interpretation.

### Exact repository refs

`research-repository-ref-lib.mjs` owns:

- exact path shape;
- repository-relative containment;
- allowed roots/top-level authority files;
- optional tracked existence/file-kind validation.

No other audit produced enough repeated compatible semantics to justify a shared domain object.

## Cross-audit findings

The second pass mattered because categories interact.

### Path syntax × provenance lifecycle

A syntax-only source-artifact contract is insufficient at repository-integration time. The constructor now enforces exact path shape; the integration audit enforces target existence.

Conversely, restricting refs only to directory roots was too narrow for legitimate top-level authorities such as `AGENTS.md`. The shared ref owner now supports explicit top-level files without accepting arbitrary prose.

### Relation identity × applicability

A stable question ID or authored report path proves what evidence is related to. It does not prove that the evidence is fresh, protocol-compatible, population-supported or admissible for the current claim.

Question dossiers now say applicability is unassessed rather than allowing a current-authority label to imply more.

### Independence × unit topology × transfer support

Fresh rows are not automatically independent evidence if they share dependence clusters, and independent samples are not automatically useful transport evidence if the target response region lacks treatment opportunity.

The H3 transfer design was checked across all three dimensions and remains clean for its actual narrow claim: disjoint level rows, same technique/source frame, with explicit target-support diagnostics.

### Instrument support × measurement reactivity

An observer can preserve solver decisions while still changing how much search is observed under wall-clock termination. Durable method now distinguishes semantic parity from timing/coverage parity.

### Agent context × distributed knowledge

Context-budget pressure revealed historical chronology living in a current authority. The fix was ownership cleanup, not a larger byte ceiling. The same pass also found that newly created shared primitives had not yet been routed from the operating model.

## Durable doctrine changes

The operating model now explicitly carries:

- unit-topology and exact-repository-ref shared owners;
- wall-clock observer coverage/parity discipline;
- claim-relative transfer response-region support.

Detailed forensic reasoning stays in dated reports rather than bloating live method/priority authorities.

## Stop rule

Do not continue inventing adjacent audits merely because another category name can be coined.

Reopen when one of the recorded triggers actually occurs:

- new compatible data makes a blocked join/analysis legal;
- two live consumers repeat the same currently-specialist semantics;
- a transition/path/identity/observer failure recurs in a materially new place;
- a current claim needs broader transfer or invalidation support than existing owners provide.

Until then, the highest-value work returns to the solver research queue and new-solve economics.
