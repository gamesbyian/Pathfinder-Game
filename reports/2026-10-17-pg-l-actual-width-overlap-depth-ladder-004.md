## Causal inference boundary

The sequence is [PG-L 001](2026-10-17-pg-l-canonical-action-overlap-result-001.md) (width 500, isolated scorers, 29.14% mean exact-path Jaccard), [PG-L 002](2026-10-17-pg-l-static-policy-eligibility-result-002.md) (both actions *listed*, but not observed to execute) and [PG-L 003](2026-10-17-pg-l-actual-production-dispatch-canary-003.md) (only **three of eight** initial frozen parents actually ran both scorers with positive work within a 250k-base-work invocation). This new result closes precisely the missing **width/gate/work-relevant isolated overlap** measurement on those three predeclared opportunity parents. It does *not* instrument actual cross-attempt histories inside one production invocation.

The comparison uses actual production target scorer names `objectiveFirst` and `intersectionHarvest` and the source-observed gate and width 5000. Each attempt has a fresh solver prep, with no hints, reference paths or prior per-level outcomes supplied. Each configuration runs once with the canonical parent-expansion observer absent and once present; all 12 scorer/dose OFF/ON pairs match `found`, full solution identity, status, canonical work and reported nodes exactly. For each dose the complete **packed parent path history** is SHA256-keyed after production generation; only matching *entire* paths are considered exact overlap. Prefixes of eight moves are coarse basin tags only, not safe search states.

The historical production ledger identifies R02781's `intersectionHarvest` action at width 5000 but does **not** identify whether it used the plain or mechanic-bucket retention offering, both of which were statically eligible. The research replay explicitly uses plain retention. R02579 and R02037's target configs are uniquely plain. Work is nominally sourced from the real production attempts and multiplied by the prespecified factor, but `beamSearchFromGate` checks work caps at phase boundaries: R02037's 1x 23,719-unit nominal arms consumed **40,133** actual units. There is no false claim of exact source work equality.
