## Major post-v2 evidence updates

### 1. Sound local improvement is not monotone solved-set improvement

BC1 is the cleanest new evidence for P175/P184/P187.

A sound prune produced **23 gains / 4 losses** on the representative random-300 production A/B and an additional solved-control loss. The losses cannot be caused by pruning a valid completion; they arise from finite-search trajectory perturbation. Conversely, many gains arise because removing dead candidates frees scarce beam occupancy.

This materially strengthens:
- P050 — frontier composition can preserve/extinguish the only live basin;
- P141/P184 — the frontier should sometimes be reasoned about as a set of scarce future options rather than independent scores;
- P175 — net positive solve count can conceal capability exchange;
- P187 — stronger local reasoning is not monotone in solved-set capability under a fixed envelope.

It does **not** create a new parent premise. v2 already had the right parent.

### 2. Topology became production-useful, but compact topology did not become generally compressible

BC1 gives P012/P093 a production-positive example: a path-conditioned current-input topology consequence can be sound, cheap and decision-bearing.

Lane A C2 simultaneously closes one attractive decomposition representation: adding boundary/global accounting made decisive outcomes pure only by reducing repeated signatures to 7.14%, below the frozen compression gate.

So the updated picture is:
- topology relevance: stronger;
- one exact cut fact: production-positive;
- compact reusable separator-interface signature: tested form negative;
- broad decomposition/topology parent: still open.

This is a useful narrowing rather than a contradiction.

### 3. Phenomenon incidence and consumer value repeatedly separated

Several post-v2 results independently reinforce P198/P204:

- relational viability facts were real but had zero value at the tested D1 beam-retention seam;
- local one-successor forcedness covered 25.33% of parent expansion work, while global singleton phases represented only 0.0014% of discovery work;
- BC1-G was sound over 664,514 replayed valid-solution states but added only 2.7% incremental dead roots beyond BC1, too little to justify a production consumer.

The recurring structure is:

`real phenomenon -> possible representation -> actual decision seam -> displaced-work ceiling -> economics`

Skipping any arrow manufactures false promise.
