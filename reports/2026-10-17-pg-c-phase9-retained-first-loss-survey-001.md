## Earliest observed event versus first causal loss

- **F2 source/action absence:** one historical accepted trajectory reached the beam, ruling out total source absence for *that* witness only. Candidate coverage of all other solving basins is unknown.
- **F3 unsound rejection:** no evidence of a known-hint-path hard-prune failure in this bounded capture; all seen witness-support loss occurred at the score-width cut. This does **not** certify global hard-prune completeness/soundness for every future.
- **F4 prior commitment:** the prior ancestor decisions sufficient to make the witness competitively disadvantaged are not identified; no minimal causal intervention exists.
- **F5 ranking suppression / F6 retention extinction:** scoring-width removal of supported candidates is directly observed 28/28, supporting a narrow F6 *witness-relative* locus. It does not prove the entire frontier lacked any other LIVE completion. A scored-out hint path may be replaced by another still-LIVE solution family.
- **F7 work starvation:** after the selected known-hint support was lost, the same attempts performed additional work; this does not rule out work starvation on unobserved alternative LIVE basins.
- **F8 route/state exposure:** the known-hint prefix is an oracle-strength selector that ordinary cold repair almost never visits. The four seeded operator wins establish conditional operator reachability but *not a cold deployment trigger*.
- **F12 handoff loss:** no actual handoff context was available in this retained sample, so neither failure nor benefit of a new handoff is proven.

Every parent is therefore reported as `UNRESOLVED_EARLIER_CLASS`, with witnessed F6 and explicitly excluded overclaims, rather than assigning a confident earliest causal class.

## Falsifiable next tiny gate

The new idea is **not** “just make repair start from the known solution”; that would make the solver's decision use prior hints. The permissible current-state selector would have to operate on reconstructed, source-identified beam decisions **without access to historical solutions or their support labels**. Candidates include an ordinary retained-near-cull state or one of the actually generated score-discarded states nominated by purely current-state features; these are possibilities to test, not implemented mechanisms. Freeze that selector using no hindsight labels, then retrospectively compare its chosen prefixes with the four previously reconstructed winning prefixes and compute potential work/economics. Candidate identity must be reconstructable and bound to a concrete producer/capture version, not guessed from a loss depth alone.

If the existing `search-loss` specialist records do not provide reconstructable prefixes, first register the exact missing observable and a bounded passive capture test before writing handoff solver code. If no naturally nominatable state overlaps a useful repair completion, this formulation ends as an exposure diagnosis rather than a new solver capability. Keep the 24 historically operator-incapable cases in the negative/control stratum, not as plausible rescued cases.

This is an evidence-only Phase-9 survey and should not displace the immediate BC1-VX DFS/admissible opportunity gate.
