## What remains deliberately incomplete

### Accepted-path explicit substitution cohort

The seven-level cohort from Audit 3 was frozen before outcome interpretation, but an explicit path/signature substitution run was not executed because the maintained analyzer lacked a clean substitution input at audit time. The producer now retains enough oracle identity for such a run to be scientifically meaningful.

**Disposition:** do not run merely to close the audit. Execute only if a live solver mechanism nomination depends on stability across alternate valid representatives/path-set views.

### Durable experiment evidence retention

Audit 1 demonstrated that some modern decision-bearing conclusions are independently reconstructable only while Actions row artifacts remain available. Audit 6 correctly elevated durability into Resource Contract closeout semantics, but no branch in this program implemented a durable producer/archive path.

**Disposition:** real implementation debt. Implement prospectively in the existing experiment evidence topology. The smallest useful retained bundle is the declared/final experiment contract or manifest plus combined primary rows and enough execution/source identity to recompute population integrity, gains/losses, participation and work. Do not rerun historical experiments merely to backfill this.

### Class-3 exact-action dose partition

Audit 2 intentionally stopped after proving that the existing Class-3 atlas label was too strong. It did not determine which of the 37 rows are genuinely comparable-work failures.

**Disposition:** potentially solve-relevant bounded follow-up. Prefer the existing stronger equal-work/production-reach and per-attempt telemetry semantics. If retained current evidence can cheaply join the 37 rows, materialize the partition before inventing new capability for those rows. If evidence is unavailable, leave them dose-unverified rather than launching broad compute solely to fill the table.

### Experiment-manifest audited-resource grade

Audit 6 nominates experiment manifests plus the decision-bearing primary-row bundle as the strongest next audited-resource candidate, but correctly does not promote it automatically.

**Disposition:** decide as part of durable-retention implementation. If that work establishes a recurring stable resource contract, add audited-resource status then. Do not commission another broad audit first.
