# A × D3 × F3 dynamic-interface reconciliation result 001

> **Status:** concluded-positive
> **Last evidence:** 2026-09-17 — zero-new-compute reconciliation of Lane A separator census, Lane D3 commutativity/mechanic attribution, and Lane F3 topology-fork/descriptor evidence on current `main`.
> **Decision:** the three lines jointly earn a bounded **nested dynamic-interface contract falsifier**, not a decomposition implementation. Static cut identity, obligation multiset, segment length, and endpoint geometry are each already known to be insufficient in relevant retained populations. The smallest defensible candidate contract has four separately testable state families: boundary kinematics, exact global accounting, mutable mechanic history, and bounded path-history/topology. These must be admitted incrementally on frozen legal prefixes and rejected if exact completion outcome still mixes within a signature.
> **Remaining gate:** freeze an independently selected legal-prefix population on balanced width<=4 Lane-A interfaces, exact-label local/global completion, then test C0→C4 signature refinements with a prespecified stop rule. No region DP, AND/OR search, decomposition routing, or topology-aware production state is earned before that falsifier passes.

## What each lineage contributes

### Lane A: where a compact interface could matter

The separator census establishes a real target population rather than an architectural fantasy:

- 121/390 Class-5 residual levels have at least one balanced, non-trivial width<=4 interface;
- 54/121 have a mechanic-aware balanced interface;
- portal mediation is essentially absent (3/4,862 measured interfaces), so portal structure should not define the primary decomposition population;
- path-history-conditioned interfaces and dynamic contract size were explicitly left unmeasured.

A therefore supplies **coverage and geometric locus**, not a state representation.

### D3: endpoint/obligation equivalence is not a state contract

D3 gives two hard constraints.

First, same interface endpoints plus the same obligation multiset does not imply substitutability. Of 12,277 candidate segment substitutions, 86.5% are illegal overall; controlling segment length raises legality to 46.6%, proving length is an important confound but still leaves more than half of matched candidates invalid.

Second, history-sensitive mechanics cannot be localized to whether the swapped segment itself touches the mechanic. On the retained flipper-bearing subset, both flipper-touching and flipper-avoiding length-matched substitutions are 0% legal. Support is only three qualifying levels and is dominated by one board, so this does **not** prove a universal flipper mechanism. It does rule out a contract that records only local segment mechanic contact.

D3 therefore requires at least:

- boundary entry/exit continuity, including heading/direction-sensitive legality;
- exact length accounting;
- mutable mechanic state that may have been established outside the local region.

### F3: endpoint geometry plus ordinary progress can hide future-relevant topology

The topology fork provides the complementary failure mode. Fork pairs share the same anchors and matched ordinary mechanic-progress state, yet exact completion feasibility can differ. The expanded population contains 14 pairs across seven parents, with eight discordant pairs across four discordant families.

The attempted cheap side descriptor is useful diagnostically but not a sound contract token where it matters:

- all 9 decision-relevant discordant decisive-puncture rows have tied closest points;
- the cheap descriptor is 7/9 on those rows, informative but not sound;
- the untied subset is 8/8 but contains zero decision-relevant discordance;
- tie-aware local refinement does not improve the failure mode without approaching the full path observer.

F3 therefore rules out “same endpoints + cheap local side bit” as a sufficient dynamic interface representation. Some bounded path-history/topology token must either be represented soundly or the contract must abstain.

## Minimal candidate contract, partitioned by evidence source

Do **not** start by serializing every solver field. Test a nested contract in which each family has an explicit reason to exist.

### C0 — static interface identity

- interface/cut identity;
- current side / region identity.

Expected role: negative control. Existing evidence makes sufficiency unlikely.

### C1 — boundary kinematics

Add only state needed to make crossing legality well-defined:

- interface entry/exit cell;
- incoming/outgoing direction or equivalent heading continuity;
- portal-jump boundary state only when the crossing itself requires it.

Evidence basis: D3's dominant length-matched failures are ordinary move/adjacency continuity failures despite matched interface/obligation identity.

### C2 — exact global accounting

Add scalars/obligations whose conservation is globally binding:

- path length used/remaining;
- intersections used/remaining;
- outstanding must-pass/must-cross obligations partitioned by region/interface where representable.

Evidence basis: D3 demonstrates length as a large independent confound; Lane A's own preflight names length/intersection coupling as a contract-explosion risk.

### C3 — mutable mechanic history

Add the smallest canonical current-state representation needed for mechanics whose legality depends on prior path history:

- flipping-filter phase/used-state in its existing canonical runtime form, not a local “segment touched flipper” flag;
- filter/turn state that affects boundary continuation;
- portal state only where current runtime semantics make it continuation-relevant.

Evidence basis: D3's segment attribution falsifies local mechanic contact as sufficient. This family is a candidate representation of the live global-history hypothesis, not a claim that flippers caused the retained failures.

### C4 — bounded path-history/topology

Add only a sound bounded representation of prefix-induced geometry/topology relevant to this interface:

- occupancy of the interface/cut and a bounded neighborhood when it can change side accessibility;
- separator-side commitment / topology token for punctures whose phase can alter completion feasibility;
- **abstain rather than substitute** when the cheap F3 descriptor is in its tied/unsound regime unless a sound token is available.

Evidence basis: F3 directly shows future-feasibility differences at matched anchors and ordinary progress state. Its cheap descriptor is not safe on decision-bearing rows.

## The earned experiment

The next experiment should be a **signature-collision falsifier**, not a solver treatment.

### Population

1. Start from Lane A's balanced width<=4 interface population.
2. Freeze legal production-search prefixes independently of any exact label or whether a candidate signature looks promising.
3. Prefer multiple prefixes per parent/interface for collision discovery **and** enough independent levels for generalization; preserve parent/frontier ancestry.
4. Record interface geometry before exact labelling.
5. Exact-label whole-prefix completion and, where feasible, the smaller-side residual completion question.

The generic production-frontier sampler merged in #1864 is appropriate population-construction infrastructure, but the sampler's multiple siblings from one level remain one independent parent unit.

### Analysis

For each nested contract C0…C4:

- group rows by canonical signature;
- count groups containing both exact-LIVE and exact-DEAD outcomes;
- report rows, groups, mixed groups, parent count, and whether mixing occurs within the same parent or across independent parents;
- report signature cardinality / bytes or another explicit complexity proxy;
- separately report abstention/unrepresentable rows;
- never promote a lower-mixing signature merely because it became near-unique.

This is deliberately a behavioral-quotient-style falsifier with stronger semantics: exact labels, a prespecified interface population, nested evidence-earned fields, and a complexity/abstention accounting.

### Stop rules

Stop **negative / contract-explosive** if:

- C4 still mixes exact completion outcomes in same-signature rows on soundly represented cases; or
- eliminating mixing requires near-unique/full-prefix identity, unbounded occupancy, or effectively the full topology observer over broad board state; or
- useful collision coverage collapses so far that the contract has no compression advantage.

Stop **mixed** if:

- one coherent mechanic/interface subpopulation passes while others require explosive state; preserve only that subpopulation.

Advance **bounded positive** only if:

- a compact Ck signature has non-trivial repeated collisions;
- no mixed exact outcomes appear in the tested sound subset;
- the effect holds across multiple independent levels;
- representation cost remains materially below retaining/replaying the full prefix;
- the same signature can be computed from cold current-input state without historical labels or stored winners.

A bounded positive earns only the smallest consumer, preferably a local interface-feasibility prune/query. It does not directly earn region DP or an AND/OR engine.

## Cross-lineage conclusions

1. **A is not merely waiting for exact labels anymore.** D3/F3 narrow what must be tested, so a fresh exact campaign should test nested contract sufficiency rather than only “local side infeasible ⇒ global DEAD.”
2. **D3's useful transfer is representational, not a repair operator.** Its strongest contribution here is proof that interface equivalence requires direction/accounting/history state.
3. **F3's useful transfer is a required abstention/soundness boundary.** The cheap topology descriptor is capability-memory evidence but cannot be smuggled into C4 as if 77.8% decision-row agreement were sound.
4. **The three lines jointly provide a cheaper architecture falsifier.** If C0→C4 cannot achieve compact outcome-pure collisions, decomposition can be closed on contract explosion before any region search is implemented.

## Disposition

This reconciliation **advances Lane A one gate**: from an underspecified “dynamic contract needed” state to a concrete nested contract falsifier with explicit negative controls and stop conditions.

It does not change D1's position as the active WS2 execution gate. The A experiment remains a bounded retained/offline/premise-acquisition descendant that may proceed when its exact-label population is available without displacing D1's already-earned production-inert observation.
