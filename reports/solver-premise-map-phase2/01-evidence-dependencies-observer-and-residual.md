## Method and provenance guard

This pass treats Phase-1 findings as observations to synthesize, not as independent empirical replications. Every synthesis below records shared ancestry explicitly. The Phase-1 lens count is never used as confidence multiplication.

The strongest shared source families are:

1. the same 142-proposition / 166-relation frozen v1 map and hardening overlay;
2. the same current residual and retained experiment corpus;
3. the same research-function decomposition that influenced M9/M10 and the hardening overlay;
4. repeated use of exact LIVE/DEAD sibling populations, especially the `R03147` multi-pick asset;
5. repeated use of current Class-5 residual populations or descendants of the same construction machinery.

Accordingly, repeated appearance across M1/M6/M7/M9/M10/M12 is conceptual triangulation, not empirical independence.

## S2-C01 — measurement authority is a carried state, not a property of a number

**Phase-1 origins:** M1.1/M1.5; M3.2/M3.7; M6.4/M6.7; M8; M10 `recognize -> measure` and `measure -> infer`; M12 O002/O004/O006. Relevant frozen premises include P003, P005, P135, P151, P161, P175, P181, P187, P188, P197, P198, P199.

**Structural argument.** Across these findings, the repeated failure mode is not bad measurement. It is qualifier loss between measurement and decision. The same scalar or binary result has different decision authority depending on population, participation, witness multiplicity, architecture epoch, work contract, instrumentation regime, causal design, maturity gate, and intended consumer. P197/P198 already name authority and maturity, but Phase 1 shows those qualifiers are not uniformly attached to evidence as it crosses interfaces.

**Competing interpretations.** (A) This is a runtime/state problem: evidence should travel as a typed object carrying authority metadata. (B) It is research-governance only: disciplined reports and preflights are sufficient, and runtime code should not know these dimensions. (C) It is partly ontology: the premise map needs better evidence-method vocabulary, while the solver remains unchanged.

**Pseudoreplication / evidence dependence.** Most supporting Phase-1 lenses inspect the same frozen governance concepts. Their agreement is highly dependent. Independent support comes more from concrete historical corrections in the queue, such as Class-3 being changed from apparent negative to `dose-unverified` because per-technique telemetry was absent, and Lane F3's population expansion overturning the earlier interpretation of the untied subset without changing the raw descriptor behavior.

**Epoch conditioning.** High. The specific metadata needed changes when scheduler, candidate grammar, telemetry, or residual population changes. The general need to preserve authority is portable.

**Discriminator.** Take a small sample of live research conclusions and trace whether a downstream queue/decision consumer can recover, mechanically or from one canonical record, population identity, work contract, participation, instrumentation, causal method, and maturity. If the answer is consistently yes without reconstruction, the missing-state interpretation weakens.

**Smallest missing primitive.** A read-only `evidence-contract` record or query that binds result -> population -> work contract -> participation/dose -> causal method -> epoch -> authority/maturity -> permitted decision consumers. This can begin as research tooling rather than solver runtime state.

**If true.** Several apparent stale-authority and measure->infer problems become one testable interface problem: evidence objects lose decision rights in transit.

**If false.** Retire the broad evidence-object proposal and keep the fixes local to documentation/preflight discipline.

**Confidence:** high that qualifier loss is a recurrent research risk; medium that a single explicit contract is the right repair.

**Type:** ontology/interface issue, not yet a new solver premise.

## S2-C02 — current residual measurements are often negative images of prior capabilities

**Phase-1 origins:** M1.2; M8; M9.6/M9.7; M10 measurement boundaries; P005, P181, P182, P187, P199.

**Repository evidence.** The live queue defines the production boundary as 101/102 C1 + 1,169/1,700 C2, with a 531-level residual, and explicitly warns that residual/participant claims are population-conditional. Current Class-5 is 390 levels after earlier capabilities have removed easier/opposite cases. Lane A measures 121/390 balanced narrow interfaces on that survivor population; this is not automatically a property of Pathfinder levels generally.

**Structural argument.** Many Phase-1 questions ask whether a phenomenon is common, predictive, or missing. On an earned residual, prevalence can increase precisely because preceding techniques already solved levels lacking the phenomenon. Conversely, a useful feature can appear weak because earlier techniques preferentially removed the cases where it paid. This makes the residual a complement of the current portfolio, not a neutral sample.

**Competing interpretations.** (A) Residual enrichment is a nuisance to correct. (B) It is exactly the relevant population for complementary solve acquisition, so the negative-image character is a feature, not a bias. (C) Both are true depending on whether the claim is about Pathfinder semantics or current-portfolio economics.

**Evidence dependence.** Lane A, D, E, F and Card-E are all downstream of current portfolio construction. They are not independent samples of the game's level universe. Within-parent assets such as R03147 further narrow generalization.

**Discriminator.** Re-express each strong current positive in two claims: `phenomenon exists/prevalence in target residual` and `phenomenon generalizes beyond the current predecessor portfolio`. Only the second requires a predecessor-perturbed or broader population. If decision impact is strictly complementarity under the current portfolio, no broad-population correction is required.

**Smallest missing primitive.** A residual provenance join that can answer: which predecessor capabilities removed which rows before this population was formed, and which measured feature is enriched/depleted relative to the predecessor population?

**If true.** Historical portability and current phenomenon prevalence should be conditioned explicitly on predecessor portfolio; some broad semantic claims should be narrowed to complementarity claims.

**If false.** Residual provenance can remain report metadata rather than becoming a routine analysis primitive.

**Confidence:** high on conditioning; medium on practical effect size for any particular positive.

**Type:** scope split / evidence-generation dependency.

## S2-C03 — observer and constructor effects are coupled more often than the reports' surface labels suggest

**Phase-1 origins:** M1.5; M3.2; M6.4; M7 A5; M10 recognize->measure; M12 O004/O006; P135, P151, P158, P161, P167, P188, P199.

**Repository evidence.** The fresh sibling program first produced zero LIVE states with a naive walk and zero LIVE among 98 single-pick production-search samples; multi-pick sampling then found real LIVE states. Lane D1's clean 18 DEAD / 2 LIVE realizability result therefore exists only after the constructor changed. Lane F3 likewise found that every decision-relevant discordant row was tied; the apparently sound untied subset had zero decision-relevant coverage.

**Structural argument.** A research observer sees the population made visible by its constructor. Sampling, reachability, prefix choice, exact-label method, and telemetry determine which states can enter the study before the observer measures them. Therefore `observer effect` should include construction-induced visibility/censoring, not just runtime telemetry overhead.

**Competing interpretations.** (A) This is simply ordinary study design and needs no unifying concept. (B) Constructor + observer should be treated as one evidence-generation pipeline because changing either can reverse the apparent finding. (C) Constructor effects matter only for state-level studies, while level-level censuses remain largely unaffected.

**Pseudoreplication.** Lane D1, Lane E, DEAD-core work, and some follow-ons reuse the same sibling-constructor lineage. Cross-result consistency on that asset is not independent replication across state-generation processes.

**Discriminator.** For a selected positive, rerun only the constructor while holding the observer fixed, then rerun only the observer while holding the population fixed. Large shifts under constructor substitution would support the unified evidence-generation view.

**Smallest missing primitive.** A population-construction manifest with constructor identity, admissibility rules, sampling policy, censoring/abstention counts, and parent/independent-unit structure, queryable by downstream reports.

**If true.** Some `phenomenon` premises should be reframed as `phenomenon under constructor C / observer O`, reducing false generalization and making replication design sharper.

**If false.** Existing population manifests are sufficient and no higher-level evidence-generation abstraction is needed.

**Confidence:** high for state-level assets; medium for universalization.

**Type:** evidence-generation dependency / scope split.

## S2-C04 — independent unit is a decision variable in its own right

**Phase-1 origins:** M7 A5, M9.9 P199, M10 transfer->recognize and recognize->measure, M11 P199, M12 O006.

Lane D1's 18 DEAD rows are 18 within-parent trials from one parent, while the F3 expanded set is 14 pairs across seven parent families. The raw row count therefore cannot stand in for generalization pressure. The relevant unit can be level, parent, state, trajectory, obligation configuration, or causal class depending on the claim.

**Competing interpretations.** Existing reports already state parent structure, so this is only bookkeeping. Counterpoint: P199 exists because the choice of unit changes what `replicated` means and therefore changes the next warranted experiment.

**Discriminator.** Recompute confidence statements in several current reports under alternative independent-unit choices without changing any measurements. If the disposition changes, unit selection is decision-bearing rather than cosmetic.

**Smallest missing primitive.** An `independent_unit` field in retained population/evidence manifests, allowing multiple declared units where the claim differs.

**Decision impact.** If true, population growth should target missing independent units rather than raw rows. If false, report prose is sufficient.

**Confidence:** high.

**Type:** ontology/evidence-contract issue.

## Synthesis boundary

These candidates do not alter the frozen map and do not create canonical premise IDs. They also do not imply that the solver needs runtime evidence objects. The smallest discriminating work is research-side provenance/constructor metadata and replay, not production implementation.
