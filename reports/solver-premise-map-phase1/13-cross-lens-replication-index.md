## Purpose and stop-rule discipline

This index records where independently executed preregistered lenses pointed at the same frozen object or boundary. It does **not** rerun any lens, create new candidates from combinations of findings, infer priority from replication count, or begin Phase-2 synthesis. The entries below are a lookup aid for later review.

Replication count means only “number of Phase-1 lenses whose already-recorded output discusses this object/theme.” It is not a probability, weight, confidence multiplier, or queue score.

## Sparse or lens-specific results worth preserving

Replication is not required for a finding to remain reviewable. Several Phase-1 results are intentionally sparse:

- M5 found only one strict repeated-failed-form parent, P032. This is a negative result against a sweeping “many immortal parents” story.
- M8 found no historical conclusion that could be declared wholly no-longer-decision-bearing from age/epoch drift alone.
- M12 found resource conservation (O005) already representable and irreversibility (O003) mostly representable, rather than manufacturing six ontology gaps from six stress tests.
- M6 found failure explanation→revision and participation→attribution already partially represented, narrowing rather than expanding the claimed interface gaps.
- M9 found P197-P200 had earlier semantic anchors; independent reconstruction mainly supplied repartitioning and explicit parent dimensions rather than four isolated topics.

These negative/narrowing results are retained because the preregistration requires investigative rather than confirmation-seeking use of the lenses.

## Replication interpretation rules for Phase 2

A later Phase-2 session may use this file to locate repeated objects, but it must return to the individual M1-M12 reports before drawing conclusions. Specifically:

- replication count must not become an aggregate pressure score;
- agreement among lenses must not be treated as independent empirical replication when the lenses share the same frozen source corpus;
- one lens's candidate output must not be retroactively treated as input to another lens;
- apparent contradictions between lens reports should be preserved until their scope, authority and evidence differences are checked.

This index closes cross-lens bookkeeping only. It performs no recursive mining.
