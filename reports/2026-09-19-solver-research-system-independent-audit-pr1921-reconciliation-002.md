## Executive reconciliation

The independent audit and PR #1921 converge unusually strongly.

That convergence is substantive, not just terminological. Both independently identify the same central condition: Pathfinder's remaining research-system risk is not primarily missing files, links, schemas or methodological doctrine. It is the loss or mutation of **scientific meaning across otherwise-correct boundaries**, combined with a question-generation loop biased toward objects that current solver/instrument infrastructure already knows how to represent.

PR #1921 already covers almost every major independent finding:

- actual artifact versus declared-schema auditing, including the current v3 split-brain;
- a smallest common scientific semantic kernel rather than a master schema;
- richer scientific unit topology;
- multidimensional independence and shared failure modes;
- analysis contracts, estimands and negative-result resolution;
- support/abstention-aware instrument calibration;
- claim capsules and bounded derivation/reverse invalidation;
- target/deployment envelope discipline;
- agenda provenance and proposal-set impoverishment;
- controlled non-exposure / independent inquiry;
- negative-space intersection mining;
- absence-of-representation and absent-search-object blindness;
- a tiny exact-supported completion-set discriminator before any regime framework;
- explicit protection for direct solver work and anti-recursion/ROI guards.

The independent audit therefore does **not** justify another plan, another ontology, or a broad expansion of #1921.

It earned two narrow semantic refinements:

1. **Opportunity/exposure unit belongs in the unit topology.** The existing plan separated observation, assignment, dependence, analysis and generalization units, but the repo's own opportunity-sizing method already treats the unit that actually had a causal opportunity for treatment/instrument/action as scientifically distinct. That distinction matters in late-stage participation, conditioned rescue designs, decision-observation populations and repeated within-parent opportunities.

2. **Temporal validity/current applicability needs an explicit scientific semantic.** The repo has real evidence that an observation can remain historically valid while becoming stale for a current solver decision. Frozen technique-census capability changed materially across solver revisions, and residual class membership changed when hint-provenance inputs were refreshed despite an unchanged historical production boundary. The correct abstraction is dependency- and decision-relative freshness, not time-based expiry.

Those two refinements have been integrated into the existing plan in place.

## Why opportunity/exposure is a distinct unit

The existing unit topology was already correct as far as it went. The independent pass found one scientifically meaningful role missing from the portable list.

An **opportunity/exposure unit** is the unit on which the treatment, instrument or decision could actually have changed the primary outcome.

Examples:

- a parent level can be assigned to treatment while only a subset of stage reaches are genuine treatment opportunities;
- many decision rows can be observed inside one parent, but only cutoff-bearing decisions may be opportunities for a retention treatment;
- a family perturbation can assign one parent/family while descendants differ in whether the changed mechanic relation is actually exercised;
- repeated rows can be observed and analysed while the relevant causal opportunity occurs once per parent or once per stage.

This role should not be forced into observation or assignment semantics. It also should not become another universal raw-row field. The plan now includes it only when scientifically distinct.

## Why temporal validity is not ordinary provenance

The independent audit's strongest genuinely missing plan concept was time as a scientific validity dimension rather than only a provenance timestamp.

Two current-repo cases demonstrate the issue:

1. the frozen technique census remained a correct historical record, yet spot checks showed substantial current-head capability drift under the same nominal technique/node envelopes;
2. the Class-4/Class-5 residual split changed when hint provenance was freshened even though the historical production boundary itself was held fixed.

The important distinction is:

- **was the old result correct when produced?**
- **is it still entitled to describe the current solver/population/instrument boundary?**

These are different questions.

The plan now treats freshness as dependency- and decision-relative. It explicitly rejects:

- generic evidence-expiry clocks;
- automatic salience decay;
- periodic full recomputation;
- treating historical evidence as false merely because it is old.

Cheap spot checks, changed-boundary triggers, existing capability-memory freshness rules and explicit reopen conditions are preferred.

## Plan critique after independent reconstruction

### Decomposition

The plan is large, but its decomposition is not fundamentally wrong.

The apparently broad later phases are mostly **gated investigations**, not implementation commitments. The staged order correctly demands semantic reality checks and narrow real consumers before portfolio/reflexivity machinery. This makes the plan self-pruning if the hypothesized seams are not real.

No phase was removed merely to make the document shorter. The first tranche already requires deleting/merging later plan items that current infrastructure proves redundant.

### Centralization risk

The plan's phrase "bounded research operating system" could have implied excessive centralization, but the operative text consistently prefers:

- common contracts over common implementations;
- derived views over new authorities;
- specialist payloads over forced normalization;
- local claim capsules over a global claim database;
- one queue and one premise ontology;
- preserved implementation independence where it has evidentiary value.

The independent audit therefore does not justify weakening that architecture further.

### Metadata versus rigor

The plan does not generally mistake metadata for rigor. Its strongest proposals are behavioral:

- fail-closed constructors;
- end-to-end transaction/conformance tests;
- manipulation checks;
- hard-blind confirmation only when selection pressure earns it;
- invalidation drills;
- independent inquiry;
- exact-supported discriminators;
- target/source challenges.

The temporal-validity addition follows the same rule: a freshness field without a changed-boundary consumer would be useless.

### Protecting direct solver work

Phase 29 and the staged implementation order are adequate safeguards. The independent audit found no reason to make consolidation a prerequisite for ordinary solver acquisition except where evidence correctness is actually at risk.

### Infrastructure-question coupling

This is one of the plan's strongest sections. Phases 14-28 explicitly model how instruments, answerability, candidate proposal sets, ontology, source distributions and cheap-test availability shape the question space.

The independent finding that the agenda itself behaves like a selected residual is therefore best treated as an interpretation of those phases, not a new subsystem.

## Changes made to the plan

The plan was updated in place with only the following earned changes:

1. Phase 6.3 now includes **opportunity/exposure unit** in unit topology.
2. New Phase 6.7 distinguishes **historical observation validity**, **current applicability**, and **refresh/reopen triggers**.
3. Phase 27.7 semantic interoperability verification now tests architecture/population-relative current applicability.
4. Success criteria now require both opportunity-unit semantics and non-destructive handling of stale/current evidence.
5. The first implementation tranche now includes one bounded freshness/applicability audit of an existing current-decision input.
6. Stage A explicitly includes temporal-validity semantics in the immediate semantic reality check.

No new registry, database, queue, ontology, evidence store or solver framework was added.

## Final hostile review

The independent pass did not find a hidden reason to replace PR #1921.

Its main contribution was to sharpen two boundaries that the plan had nearly, but not fully, captured:

- **causal opportunity is a unit role, not merely a row property**;
- **historical truth and current applicability are different scientific claims**.

The broader negative-space conclusions were already present in #1921, often with stronger operational guardrails than the independent audit would have invented from scratch.

That is a useful result. It suggests the current problem is no longer conceptual scarcity. The danger now is implementation overreach.

The implementation standard should remain:

> prove the seam on one real consumer, preserve unknowns and specialist meanings, and generalize only after the same semantic need recurs.

## Bottom line

PR #1921 is materially stronger than a normal infrastructure-consolidation plan because it treats research infrastructure and question generation as one coupled scientific system.

The independent audit does not overturn that architecture. It confirms it, narrows it, and adds two missing scientific semantics that current repository evidence already demonstrates are real.

The plan should proceed from the revised first tranche, not from another round of abstraction design.
