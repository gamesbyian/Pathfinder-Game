## Existing instrumentation closes the original interface gap

The actual `solveLevel` entrypoint already attaches `opts.beamResearchObserver` to the same PrepLevel that all real stages and attempts reuse. The existing `runAttempt` context supplies `attemptOrdinal`, `gateKey`, `scoringProfileId`, `beamWidth` and `mechanicBucketRetention` on generated-stage records. The existing `includeParentExpansionWork` gives literal reconstructed full paths and native parent expansion `workSpent`. Therefore no production or solver implementation changes are required for an initial chronological duplicate-expansion shadow.

The [script](../scripts/stress/pg-l-same-invocation-expansion-shadow.mjs) runs one unmodified actual `createSolver().solveLevel` control and one observer-attached execution per source puzzle with `baseWorkBudget=250000`, `nodeBudget=250000`, `timeBudgetMs=600000`, `strictTotalWorkBudget=true`. No hint/result/reference truth is passed to either call. Compare exact solve status, solution, canonical work, nodes and per-attempt identity/work/status across OFF and ON. Any discrepancy fails the entire experiment. The observer never changes `PrepLevel`, score, prune, stage plan or work meter.

For every real generated parent at the frozen target width/scorer and gate, the observer stores its full packed path as an identity within this one solve and board, plus the first producing attempt ordinal and expansion work. A later **different-scorer** expansion on precisely that path is counted as a chronological duplicate opportunity. Same-scorer repeats, prefix-only similarity, other widths/gates and unfinished/absent records never contribute. Source stats include actual ordinal pairs, repeated full paths, later native work, per-path `min(first work,later work)`, tracked-key/memory bounds and exemplar SHA-256 identities.

## Frozen, inexpensive stopping rules

1. **Source replay:** both parents showed actual prior production co-dispatch at the same gate and width5000, in the [24-parent source ledger](stress/pg-l-independent-dispatch-24-20261018-001.json). No source substitution.
2. **Control identity:** final solution/status/nodes/work plus per-attempt identity and work must match. No result if the observer affects search. Wall time may differ; the generous safety clock must not censor one arm.
3. **Opportunity:** actual same-invocation target positive work on both scorers for at least one parent with **at least 1,000** canonical work units on later expansion of a full parent path previously expanded by the other scorer. Rough screening threshold only; not net work saved.
4. **Memory:** fail closed above 350,000 unique path records or 50 million key characters. Source-positive claims must not silently extrapolate from truncated observation.
5. **No direct promotion:** if positive, find a sound typed precomputation fact with fully keyed prerequisites and quantify lookup/memory costs before matched-total-work cold A/B. If no material same-call reuse, stop this selected form and do not repeat broad overlap sweeps.

Selection pressure: this is **development evidence** on two previously overlapping co-dispatch parents. It cannot establish independent generalization, correct cache semantics, a hard prune, saved work or a new cold solve. A preexisting successful production call is an unchanged control, not treatment-added capability.

The one-shot Actions workflow will be retired after source-hashed evidence is saved. Production module files are not touched.
