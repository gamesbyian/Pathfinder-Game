## Why purity is not success here

C2 has no mixed exact LIVE/DEAD signatures, but the representation now almost identifies individual prefixes. That does not establish a compact dynamic interface contract.

The nested contract explicitly treats near-unique signatures as failure because a separator interface is useful only if materially different prefixes can share one bounded future-relevant state.

C2 has crossed that boundary.

## Why C3/C4 stop here

C3 and C4 are additive:

- C3 adds mutable-mechanic state;
- C4 adds bounded path-history/topology state.

Adding fields can only split an existing C2 signature. It cannot merge C2 signatures or raise the repeated-row fraction back above 20%.

So continuing the current ladder would be scientifically incapable of satisfying the frozen compression claim.

The Lane-A sequence now says:

- C0: compressive but mixed;

This does **not** prove that all separator/decomposition approaches are impossible. It closes this prespecified nested representation form on this population.
