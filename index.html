    Editor Guide

    Building & Testing

    Pick a tool from the palette to start building! You can tap the grid to place objects or even drag them directly into position. Use the Pencil to sketch out paths and see how your level plays. Dragging items off the grid will remove them. The Trap Spots button highlights squares where a False Goal trap could work, based on the level's design.

    Solving

    Click Solve to automatically find valid solutions. It requires target metrics (Length/Crosses) to be properly set beforehand.

    Parity Warnings

    When a true Goal and target Length are set, the editor may draw a red cross-out over gates and portal terminals on the wrong checkerboard parity to reach that Goal in exactly that Length. The editor hides all parity cross-outs when any portal pair links terminals with the same checkerboard parity.

    Submitting Levels

    Once you've built something great, click Submit to send your level for review. If you've drawn a valid solution or used the solver, it will automatically include that as a helpful hint for players.

    Solve Options

    Search For Varied Hints

    Finds valid solutions and saves them all — the number is how many distinct approaches the hint display should be able to present (up to that many, or all the level offers). Finding 2 or more distinct hints also unlocks the level's heat map overlay.

    Find Every Solution

    Exhaustively finds every possible solution. This can take 20+ minutes depending on the level and your device — you can stop at any time and everything found so far is kept.
